# АгроЭкспо 3D — инструкция

Две части: для посетителя выставки и для организатора, который ведёт демо и смотрит статистику.

- Выставка: https://chernoknipnick.github.io/agroexpo3d/
- Статистика (только для организатора): https://chernoknipnick.github.io/agroexpo3d/admin.html
- Код: https://github.com/chernoknipnick/agroexpo3d

---

## Часть 1. Посетителю

### Как зайти

1. Откройте ссылку в браузере на компьютере или телефоне. Ставить ничего не нужно.
2. **Шаг 1 регистрации.** Ник, роль (фермер, агроном, механизатор, руководитель, молодой фермер), цвет одежды и головной убор. Кнопка «Дальше» или `Enter`.
3. **Шаг 2 регистрации.** Хозяйство: название, регион, площадь, культура, ваш трактор и сколько их. От этих данных зависит расчёт выгоды на тест-драйве. Поле можно построить по спутниковому снимку (см. ниже). Кнопка «Войти на выставку».

Прогресс хранится в браузере. Если зайти с того же устройства и браузера, всё сохранится.

### Управление

| Клавиши | Что делают |
|---|---|
| `W` `A` `S` `D` | идти (камера сама разворачивается за вами) |
| `←` `→` | повернуть камеру |
| `↑` `↓` | приблизить, отдалить |
| `Shift` | бег |
| `Space` | прыжок |
| `E` | действие рядом: карточка, стенд, консультант, квиз, кофе |
| `I` | осмотр ближайшего трактора |
| `Q` | квесты и ачивки |
| `R` | рейтинг «Лидеры дня» |
| `T` | навигация и телепорт |
| `Z` | реакции: эмодзи над головой |
| `B` | бонусы за баллы |
| `F` | моя ферма |
| `G` | дашборд для экспонентов |
| `C` | вид камеры: за спиной, издалека, сверху |
| `M` | мини-карта |
| `N` | звук |
| `H` | все клавиши |
| `1`…`9` | кнопки в открытой панели (у каждой кнопки подписана её клавиша) |
| `Esc` | закрыть |

Мышь необязательна, но работает: можно тянуть камеру и крутить колесо. На телефоне слева внизу джойстик, а кнопки нажимаются пальцем.

### Что делать на выставке

Вверху экрана есть подсказка с текущей целью, стрелкой и расстоянием, на полу горит маяк. Так проще всего пройти всё по порядку.

- **Стенды.** Три экспонента: «СтепьМаш» (СМ-2400), «Колос-Техника» (КТ-180), «ПолеПро» (ПП-300). Зайдите на стенд, подойдите к трактору и нажмите `E`, чтобы открыть карточку: мощность, расход, производительность, цена.
- **Осмотр трактора** (`I` у трактора). Камера облетает машину. `1` капот, `2` дверь, `3` фары, `4` двигатель (с дымом и звуком), `5` маячок, `E` тест-драйв, `Esc` выход. Подписи показывают характеристики узлов.
- **Буклеты.** Оранжевая стойка на каждом стенде, `E`, +15 баллов.
- **Консультант Ольга** на стенде «СтепьМаш»: цены, лизинг, трейд-ин, сервис.
- **Агро-квиз.** Стойка с «?», 6 вопросов, +10 за каждый верный ответ.
- **Кофе-поинт** в углу павильона.
- **Тест-драйв.** Киоск на стенде, кнопка в карточке или ворота «Выход в поле». Сначала сезон: ваша техника против новой на вашем поле, с графиками затрат и окупаемости. Потом «Сам за рулём»: вспашка с клавиатуры (`W`/`S` газ и тормоз, `A`/`D` руль, `Space` плуг, `V` вид, `Enter` завершить). Засчитываются покрытие поля и перекрытия.
- **Заявка экспоненту** после тест-драйва: имя и телефон. В демо заявка остаётся в вашем браузере и экспоненту не уходит.

### Баллы, уровни, квесты

- Баллы: стенд +10, карточка +5, осмотр +10, буклет +15, верный ответ +10, тест-драйв +50, вспашка +30 (и ещё +40, если покрыто 90% поля и больше), заявка +40, кофе +5, вопрос консультанту +2.
- Уровень растёт каждые 120 баллов: гость выставки → агроном-стажёр → агроном → главный агроном → механизатор года → агромагнат.
- Квесты (`Q`): посетить 3 стенда, найти самый экономичный трактор (сравните л/га в карточках и нажмите «Это самый экономичный» у нужного), тест-драйв, ответить на все вопросы квиза.
- Ачивки: первый урожай, экономист сезона (выгода от 1 млн ₽), пахарь (90% поля), знаток (весь квиз без ошибок), инженер (осмотрены все три трактора), механизатор года (все квесты).
- Бонусы (`B`): витрина призов. В демо баллы ни на что не меняются.

### Вместе с другими

- Другие посетители видны в павильоне с ником и уровнем. На мини-карте это крупные цветные точки, вверху слева счётчик «Сейчас на выставке».
- `Z` → выберите реакцию (👋 Привет, 👍 Класс, 🔥 Огонь, 🚜 Хочу такой, ❓ Есть вопрос, 😂 Ха-ха). Она 4 секунды висит над вашей головой, и её видят все.
- Серые точки на мини-карте и люди с белыми табличками — боты-посетители. Они ходят по стендам, к квизу, за кофе и в поле, разговаривают друг с другом. Чем больше живых людей, тем меньше ботов.
- Рейтинг (`R`) и табло «Лидеры дня» в павильоне показывают реальных игроков за сегодня. Пока включение не завершено, там демо-хозяйства.

### Поле по спутниковому снимку

«Моя ферма» → «Поле со спутника» (или на шаге 2 регистрации):
1. Загрузите скриншот участка с любой карты, где видна шкала масштаба.
2. Кликните по двум концам шкалы и введите её длину в метрах.
3. Обведите границу поля кликами. Площадь в гектарах посчитается сама, и тест-драйв пойдёт на этом поле.

## Часть 2. Организатору

### Что где лежит

| Что | Где |
|---|---|
| Игра | `index.html`, `app.js` (логика), `models.js` (3D-модели), `vendor/three.min.js` |
| Подключение к серверу | `config.js`: адрес и публичный ключ Supabase |
| Клиент Supabase | `vendor/supabase.js` |
| Статистика | `admin.html` |
| База | `supabase.sql` (журнал), `supabase-2-leaders-admin.sql` (рейтинг и доступ админа) |
| Документы | `docs/`: эта инструкция, ревью и ТЗ |

Сервер — бесплатный проект Supabase, у него одна таблица `events`. Каждое действие посетителя записывается в неё строкой: кто, когда, ник, роль, регион, хозяйство, баллы, уровень, что сделал. Сайт может только добавлять строки. Читать их может только админ.

### Как обновить сайт

Сайт раздаёт GitHub Pages из ветки `main`. Любой пуш в `main` через 1–2 минуты появляется по ссылке.

После правки `app.js`, `models.js` или `config.js` увеличьте номер версии у соответствующего скрипта в `index.html` (`app.js?v=7` → `app.js?v=8`). Иначе часть посетителей до 10 минут будет получать старый файл из кэша.

### Включить рейтинг и статистику (один раз)

1. Supabase → **Authentication → Users → Add user → Create new user**: ваш email и пароль, галочка **Auto Confirm User**.
2. **SQL Editor → New query**: вставьте весь `supabase-2-leaders-admin.sql` и нажмите **Run**. Внизу должен появиться ваш email в колонке `admin`. Если вместо этого красная ошибка, сохраните её текст.
3. **Authentication → Sign In / Providers**: выключите **Allow new users to sign up**, чтобы никто не мог завести себе пользователя.
4. Откройте `admin.html` и войдите.

Проверить, что всё применилось: табло в павильоне должно показать ваш ник после того, как вы наберёте баллы.

### Ваш эльф на выставке

Если вы вошли в `admin.html`, откройте выставку в том же браузере. Вы появитесь своим эльфом из `ELF.blend`, над головой будет подпись «Админ», а в верхнем меню — кнопка «Статистика ↗». Все посетители видят вас этой моделью. Обычные игроки остаются человечками.

Как обновить модель после правок в Blender (из папки репозитория):

```
blender.exe -b C:\Users\Admin\Documents\ELF.blend --python tools\export_elf.py -- models\elf.glb
```

Скрипт выбрасывает камеру, свет, дым, зубы и язык, запекает модификаторы, сажает доспехи и сигарету на кости, упрощает материалы MPFB, ужимает текстуры до 1024 px и пишет GLB (сейчас 1,9 МБ). Сам `.blend` при этом не меняется. Потом увеличьте номер в `models/elf.glb?v=1` (функция `elfLoad` в `app.js`) и запушьте.

### Что показывает статистика

- Кто сейчас на выставке, в реальном времени.
- Посетители, заходы, сколько играли, среднее время захода, тест-драйвы, заявки, средние баллы.
- График посетителей по часам (сегодня) или по дням.
- Что делают: стенды, карточки, осмотры, буклеты, консультант, квиз, тест-драйвы, вспашка, заявки, кофе.
- Интерес к каждой модели: карточки, осмотры, тест-драйвы, заявки.
- Регионы игравших.
- Таблица посетителей. Нажмите на строку, чтобы увидеть все действия человека по времени.
- Период: сегодня, 7 дней, 30 дней, всё время. Данные обновляются раз в минуту или по кнопке.

Удалить записи (например, свои тестовые) можно в Supabase → Table Editor → `events`: отметить строки → Delete. Или SQL: `delete from events where nick = 'Мой тест';`.

### Как поменять содержимое

Всё лежит константами в начале `app.js`:

| Что | Константа |
|---|---|
| Цена дизеля, ставка механизатора, длина смены | `FUEL`, `WAGE`, `SHIFT` |
| Культуры: норма часов на га, агросрок, урожайность, цена | `CROPS` |
| Своя техника посетителя и цена трейд-ина | `OWN` |
| Тракторы экспонентов | `EXPO` |
| Стенды: название, слоган, цвет, место | `STANDS` |
| Демо-хозяйства для рейтинга | `FARMS` |
| Ответы консультанта | `FAQ` |
| Вопросы квиза (третье число — номер верного ответа с нуля) | `QUIZ` |
| Призы | `PRIZES` |
| Точки телепорта | `PLACES` |
| Боты: имена и уровни | `BOTN` |
| Реакции | `REACT` |

### Лимиты бесплатного Supabase

До 200 человек онлайн одновременно, 2 млн сообщений реального времени и 500 МБ базы в месяц. Один игрок в движении шлёт около 6 сообщений в секунду, их получает каждый, кто онлайн. Для показа и тестов хватает с большим запасом. Для настоящей выставки на сотни человек нужен платный тариф или более редкая отправка координат.
