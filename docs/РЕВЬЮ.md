# АгроЭкспо 3D — ревью

Состояние на 25.10.2026. Ветка `main`, около 2 100 строк своего кода: `app.js` 1 175, `models.js` 372, `index.html` 375, `admin.html` 211.

## Итог

Как демо для заказчика и инвесторов проект готов. Он открывается по ссылке без установки, выглядит цельно, его можно пройти с клавиатуры от начала до конца. В нём есть живые люди, журнал посещений и статистика. Сильная сторона — расчёт выгоды на поле самого посетителя: это то, ради чего фермер останется на сайте.

Для настоящей выставки с призами и заявками его пока выпускать нельзя. Баллы считает браузер, и их можно подделать. Заявки никуда не уходят. Канал мультиплеера ничем не защищён. Код написан плотными строками в одном большом файле, и дорабатывать его будет всё дороже.

## Что сделано хорошо

- **Ценность для посетителя.** Тест-драйв сравнивает свою технику с новой на своём поле, по своей культуре и площади: топливо, люди, ТО, потери урожая из-за затянутых сроков, трейд-ин, окупаемость. Поле можно построить по спутниковому снимку.
- **Вход без барьеров.** Ссылка, два коротких шага регистрации, и ты в павильоне. Работает и на телефоне: есть джойстик.
- **Клавиатура везде.** У каждой кнопки подписана клавиша, `H` открывает полный список. Демо можно показывать, не трогая мышь.
- **Игровой каркас.** Цель дня со стрелкой и маяком, квесты, уровни, ачивки, рейтинг. Новичок не теряется.
- **Графика без внешних моделей.** Тракторы, люди и павильон собраны из кода, неподвижные детали склеены, чтобы было меньше вызовов отрисовки.
- **Живая выставка.** Мультиплеер, реакции, боты с осмысленным поведением, которых становится меньше, когда заходят люди.
- **Данные для заказчика.** Журнал каждого действия, страница статистики с воронкой, интересом к моделям и лентой действий каждого посетителя.
- **Безопасность базы по умолчанию.** С ключа сайта можно только добавлять строки. Читать их может только админ. В интерфейсе ники и тексты экранируются.
