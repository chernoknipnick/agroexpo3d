# АгроЭкспо 3D — демо онлайн-агровыставки

Браузерный прототип онлайн-выставки агротехники: 3D-павильон со стендами экспонентов, детальные модели тракторов, тест-драйв на своём поле, геймификация и дашборд для инвесторов.

## Как запустить

**Проще всего:** распакуйте архив и откройте `index.html` двойным кликом в Chrome, Edge, Firefox или Яндекс Браузере. Установка и сборка не нужны.

Если браузер что-то блокирует при открытии файла с диска, запустите любой статический сервер:

**Python (есть почти везде):**
```bash
git clone <адрес репозитория> agroexpo3d
cd agroexpo3d
python3 -m http.server 8080
```
Затем откройте http://localhost:8080

**Node.js:**
```bash
npx serve .
```

**GitHub Pages:** Settings → Pages → Deploy from a branch → ветка `main`, папка `/ (root)`. Через минуту демо будет доступно по ссылке вида `https://<аккаунт>.github.io/<репозиторий>/`.

Сборка не нужна: чистые HTML, CSS и JavaScript. Three.js r152 лежит в `vendor/`, интернет нужен только для шрифтов (без него подставятся системные).

## Что внутри

| Файл | Содержимое |
|---|---|
| `index.html` | Разметка интерфейса и стили |
| `app.js` | Павильон, управление, квесты, тест-драйв, поле, дашборд |
| `models.js` | Процедурные 3D-модели: трактор, люди, окружение |
| `vendor/three.min.js` | Three.js r152 |

## Управление

| Клавиши | Действие |
|---|---|
| `W A S D` | Ходить (камера сама разворачивается за персонажем) |
| `← →` / `↑ ↓` | Повернуть камеру / приблизить |
| `Shift`, `Space` | Бег, прыжок |
| `E` | Действие рядом (карточка, стенд, консультант, квиз) |
| `I` | Осмотр ближайшего трактора: `1` капот, `2` дверь, `3` фары, `4` двигатель, `5` маячок, `E` тест-драйв |
| `Q R T B F G` | Квесты, рейтинг, навигация, бонусы, ферма, дашборд |
| `C`, `M`, `N` | Вид камеры, мини-карта, звук |
| `H` | Все клавиши |
| В поле: `W S A D`, `Space` | Вести трактор, опустить или поднять плуг |

Во всех панелях кнопки нажимаются цифрами, подсказка клавиши показана на самой кнопке. На телефоне работает виртуальный джойстик.

## Сценарий демо

1. Регистрация: аватар, данные хозяйства, площадь, культура, текущая техника. Поле можно построить по спутниковому снимку со шкалой масштаба.
2. Павильон: три стенда, карточки техники, консультант, буклеты, агро-квиз. Навигатор вверху ведёт по квестам.
3. Тест-драйв: сезон вашей техникой и новой на вашем поле. Итог — выгода в год, срок окупаемости, графики, заявка экспоненту.
4. «Сам за рулём»: вспашка с клавиатуры с подсчётом перекрытий.
5. Дашборд (`G`): воронка, посещаемость, популярные модели, активность по часам.

## Важно

- Экспоненты «СтепьМаш», «Колос-Техника», «ПолеПро» и их характеристики вымышлены. Модели собственной техники пользователя (МТЗ, К-700 и др.) — с ориентировочными параметрами.
- Цифры дашборда демонстрационные. Прогресс посетителя хранится только в его браузере (localStorage), бэкенда нет.
- Расчёт сезона: дизель 68 ₽/л, механизатор 450 ₽/ч, смена 12 ч, потери урожая 0,6% за каждый день сверх агросрока. Константы — в начале `app.js`.
